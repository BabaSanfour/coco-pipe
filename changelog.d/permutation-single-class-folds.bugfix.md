A test fold with a single class no longer stops a classification run unless a requested metric needs both classes (ROC-AUC, average precision and other score- or probability-based metrics); accuracy-type metrics are computed as usual, so permutation tests on small grouped data complete. When a model fails on permuted labels, the assessment raises with that model's error instead of `KeyError: 'Model'`, and a model that fails inside a decoding unit gets a `status="failed"` record instead of disappearing from the sweep.
